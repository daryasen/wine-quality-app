# Подбор хороших вин

Приложение использует сохранённую логистическую регрессию, внутри приложения модель не обучается

Проверено на Python 3.14.6, версии библиотек закреплены в requirements.txt

## Запуск на своём компьютере

Откройте терминал в папке wine_app и выполните

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Streamlit покажет локальный адрес, откройте его в браузере

## Что находится внутри

- app.py: четыре вкладки приложения
- model.joblib: StandardScaler и LogisticRegression в одном pipeline
- config.json: порог, выбранный на валидации
- test.csv: отложенная выборка для метрик
- requirements.txt: версии библиотек для запуска

## Что можно сделать

- Ввести 12 признаков одного вина и получить вероятность и решение
- Менять общий порог на боковой панели
- Смотреть матрицу ошибок, precision, recall, F1 и точки на ROC- и PR-кривых
- Загрузить CSV, получить предсказания и скачать результат
- Посмотреть коэффициенты после масштабирования признаков

Пример CSV можно скачать во вкладке загрузки

При отсутствии нужного столбца, пустом файле, пропусках или текстовых значениях вместо чисел приложение показывает понятную ошибку

## Почему используются разные виды кэша

st.cache_resource хранит один общий объект модели на сервере, копировать его при каждом перезапуске не нужно

st.cache_data подходит для таблиц и массивов, возвращает копию результата и защищает сохранённые данные от случайного изменения в другом вызове

Тестовые вероятности тоже сохраняются через st.cache_data, аргумент _model не хешируется

Если вызвать joblib.load без декоратора, модель будет заново читаться с диска при каждом изменении ползунка, что замедлит приложение

Если заменить файл модели в работающем сервере, очистите кэш Streamlit или перезапустите сервер

Проверены четыре вкладки, порог по умолчанию и крайние пороги 0 и 1

Проверены корректный CSV и ошибки при отсутствии столбца, пропусках, неверном is_red, пустых данных и текстовом признаке

## Публикация в Streamlit Community Cloud

Публичный деплой ещё не выполнен, при проверке сайт Streamlit открыл страницу входа

Для публикации нужен вход владельца в Streamlit Community Cloud, ссылки на опубликованное приложение пока нет

1. Создайте репозиторий GitHub для приложения
2. Добавьте в него файлы из этой папки
3. Войдите на https://share.streamlit.io/ и нажмите Create app
4. Выберите репозиторий и ветку, укажите app.py как главный файл
5. В дополнительных настройках выберите версию Python, совместимую с закреплёнными библиотеками, локальная проверка выполнена на 3.14.6
6. Нажмите Deploy и дождитесь запуска
7. Скопируйте публичную ссылку в последнюю ячейку ноутбука

Если папка wine_app находится внутри репозитория, укажите путь wine_app/app.py

Официальная инструкция: https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy

Документация кэша: https://docs.streamlit.io/develop/concepts/architecture/caching
